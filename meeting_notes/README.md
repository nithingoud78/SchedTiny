# Research Session Notes

## Purpose

This directory contains a dated research diary — one file per session.
Session notes are **permanent**; never delete them.

They serve as:
1. Research provenance for the MS portfolio
2. Institutional knowledge that survives researcher transitions
3. The primary source for the "Related Work" timeline in the paper
4. Documentation for experiment failure investigations

---

## File Naming Convention

```
YYYY-MM-DD_session-title.md
```

Examples:
```
2026-07-31_project-initialization.md
2026-08-05_freertos-scheduler-study.md
2026-08-12_exp001-first-run.md
```

---

## Required Sections Per Note

Every session note must include:

```markdown
## Date: YYYY-MM-DD
## Duration: X hours
## Researcher: @github_handle

### Papers Read
- [Paper Title](DOI_link) — one-sentence key takeaway

### Findings Added to research.md
- None / description → Gap N

### Code Written or Modified
- File: description of change

### Experiments Attempted
- EXP-NNN: result summary

### Blockers
- What is preventing progress?

### Open Questions Added
- New questions for open_questions.md

### Next Session Plan
- What to do in the next session
```
